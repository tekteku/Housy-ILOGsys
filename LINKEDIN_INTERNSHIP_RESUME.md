## 📋 **PROJECT OVERVIEW**

Successfully completed my end-of-study internship at **ILOGsys**, developing **Housy** - an innovative AI-powered web platform that revolutionizes construction cost estimation in Tunisia. This full-stack application combines cutting-edge artificial intelligence with real Tunisian market data to provide accurate, instant construction estimates.

---

## 🎯 **KEY ACHIEVEMENTS**

✅ **Full-Stack Development** - Built complete web application from scratch  
✅ **AI Integration** - Implemented 4 AI models (OpenAI GPT-4, Claude, DeepSeek, Ollama)  
✅ **Big Data Processing** - Integrated 6,036+ real estate properties and 1,200+ construction materials  
✅ **Production Ready** - Achieved 99.2% test success rate with comprehensive documentation  
✅ **Geographic Coverage** - Supports all 24 Tunisian governorates

## 💻 **TECHNICAL STACK**

### Frontend:
- React 18.3 + TypeScript 5.6
- Tailwind CSS + Radix UI (60+ reusable components)
- Framer Motion for animations
- TanStack Query for state management
- Wouter for routing

### Backend:
- Node.js + Express
- PostgreSQL with Drizzle ORM
- Redis for caching
- JWT authentication with role-based access control
- RESTful API architecture

### AI & Machine Learning:
- OpenAI GPT-4o (primary model)
- Anthropic Claude (premium option)
- DeepSeek (cost-effective alternative)
- Ollama (Qwen) for local/offline deployment
- Custom multi-provider fallback system
- Intelligent prompt engineering

### DevOps:
- Docker containerization with multi-stage builds
- Docker Compose for orchestration
- Automated deployment scripts
- Performance monitoring & logging
