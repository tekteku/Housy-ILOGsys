## 📋 RÉSUMÉ EXÉCUTIF

Housy est une application complète de gestion de projets de construction
spécialement conçue pour le marché tunisien. Elle offre une plateforme intégrée
pour la planification, le suivi, l'estimation des coûts et la gestion des
matériaux de construction.

🎯 OBJECTIFS PRINCIPAUX:
- Gestion de projets de construction avec suivi en temps réel
- Base de données complète des matériaux de construction tunisiens
- Estimation automatique des coûts basée sur les prix du marché local
- Assistant IA pour l'aide à la décision
- Analyse des tendances du marché des matériaux
- Gestion financière intégrée pour les projets

===============================================================================

## 🏗️ ARCHITECTURE TECHNIQUE

### STACK TECHNOLOGIQUE PRINCIPAL:

FRONTEND:
- React 18.3.1 avec TypeScript
- Vite (build tool moderne et rapide)
- TailwindCSS pour le styling
- Radix UI pour les composants d'interface
- Wouter pour le routing
- React Query pour la gestion d'état serveur
- Recharts pour les graphiques et visualisations

BACKEND:
- Node.js avec Express 4.21.2
- TypeScript pour la sécurité des types
- Drizzle ORM pour la base de données
- PostgreSQL comme base de données principale
- Helmet pour la sécurité HTTP
- Express Rate Limiting
- Session management avec Express Session

IA ET INTÉGRATIONS:
- SDK Anthropic Claude pour l'assistant IA
- OpenAI SDK (backup/alternative)
- Support pour modèles de langage avancés

OUTILS DE DÉVELOPPEMENT:
- ESBuild pour le bundling production
- TSX pour l'exécution TypeScript
- Drizzle Kit pour les migrations
- Cross-env pour la gestion d'environnement

## 🗄️ ARCHITECTURE BASE DE DONNÉES

### TABLES PRINCIPALES:

1. USERS (Utilisateurs)
   - id, email, password, name, role, phone, address
   - Gestion des profils entrepreneurs/clients

2. PROJECTS (Projets)
   - id, title, description, status, location, budget
   - Projets de construction avec géolocalisation

3. MATERIALS (Matériaux)
   - id, name, category, unit, price, supplier
   - Base de données complète matériaux tunisiens

4. PROJECT_MATERIALS (Matériaux par projet)
   - Liaison projet-matériaux avec quantités
   - Calculs automatiques de coûts

5. FINANCIAL_TRANSACTIONS (Transactions)
   - Suivi financier complet par projet
   - Types: income, expense, payment

6. PROJECT_BUDGETS (Budgets)
   - Budgets prévisionnels et réels
   - Suivi écarts budgétaires

7. PROJECT_ACTIVITIES (Activités)
   - Tâches et étapes de construction
   - Planning avec dates début/fin

8. PROJECT_DOCUMENTS (Documents)
   - Stockage plans, factures, photos
   - Système de versioning

## 🔌 API ENDPOINTS DISPONIBLES

### AUTHENTIFICATION (/api/auth)
- POST /login          - Connexion utilisateur
- POST /register       - Inscription utilisateur
- POST /logout         - Déconnexion
- GET /user           - Profil utilisateur actuel

### PROJETS (/api/projects)
- GET /               - Liste tous les projets
- POST /              - Créer nouveau projet
- GET /:id            - Détails d'un projet
- PUT /:id            - Modifier projet
- DELETE /:id         - Supprimer projet
- GET /:id/materials  - Matériaux du projet
- POST /:id/materials - Ajouter matériau au projet

### MATÉRIAUX (/api/materials)
- GET /               - Liste matériaux disponibles
- GET /categories     - Catégories de matériaux
- GET /trends         - Tendances prix marché
- GET /:id            - Détails matériau spécifique

### ESTIMATION (/api/estimation)
- POST /calculate     - Calculer estimation projet
- GET /templates      - Templates d'estimation
- POST /save          - Sauvegarder estimation

### FINANCES (/api/financial)
- GET /transactions   - Transactions financières
- POST /transactions  - Ajouter transaction
- GET /budgets        - Budgets projets
- GET /reports        - Rapports financiers

### ANALYTIQUES (/api/analytics)
- GET /dashboard      - Données tableau de bord
- GET /projects/stats - Statistiques projets
- GET /financial/summary - Résumé financier

### DOCUMENTS (/api/documents)
- GET /:projectId     - Documents d'un projet
- POST /upload        - Upload nouveau document
- GET /:id/download   - Télécharger document
